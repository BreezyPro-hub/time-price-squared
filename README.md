# Time Price Square (TTS Square)

Gann Square of Nine desk with live market data.

## Features
- Fyers live data (Nifty, Bank Nifty, MCX Crude Oil, MCX Gold, NSE stocks)
- Gift Nifty proxy
- Yahoo + Binance fallbacks
- Gann overlays, Square of Nine, cycles, decision panel

## Environment Variables (set in Vercel)
FYERS_APP_ID=T63FESIQRI-100
FYERS_ACCESS_TOKEN=<your daily token>

## Deploy
Push this folder to GitHub → Import in Vercel → Add the two env vars → Deploy
